# HireMate
HireMate è una piattaforma multimodale per la simulazione di colloqui di lavoro. Sviluppata da un team cross-funzionale (GenAI &amp; AR/VR), la piattaforma combina l'intelligenza conversazionale di agenti LLM con avatar virtuali immersivi per offrire un'esperienza di allenamento realistica, con valutazione automatica e feedback personalizzati.
